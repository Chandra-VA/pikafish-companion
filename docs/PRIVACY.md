# 隐私与本机数据

棋盘识别和引擎计算在本机运行。默认代码不把截图、局面、着法或账号信息发送到远程服务。安装依赖、下载引擎和 GitHub 仓库同步是独立的联网操作，不属于运行期分析。

屏幕捕获读取所选窗口的可见像素，再裁剪棋盘；完整窗口可能包含头像、账号或其他内容。请只在你有权查看的窗口使用，避免在截图和报告中保留个人信息。

| 数据 | 位置和用途 |
| --- | --- |
| 原始窗口画面、预览 | 运行中在内存中处理；本机 API 可获取棋盘预览 |
| `companion/templates.npz` | 本机校准掩模和标签；不提交 Git |
| `companion/web-status.json` | 默认本机诊断状态、方向和引擎变化；不提交 Git |
| `companion/.upgrade-session.json` | 特定本机更新操作临时保存的局面；不提交 Git |
| JSON 棋谱导出 | 由浏览器下载到用户选择的位置；使用者自行保存或删除 |
| 引擎验证记录与日志 | 本机排错；不提交 Git |

运行期令牌只用于当前本机服务访问，不是 GitHub 或游戏账号令牌。程序不读取密码、浏览器 Cookie、聊天或游戏网络协议，但本机窗口像素本身仍可能包含私人内容。

Git 忽略规则不会自动清除已提交的数据，也不提供文件加密。提交前查看暂存区，报告问题时使用最小脱敏例子。退出程序仅释放进程内存，不会自动删除你保存的文件。
